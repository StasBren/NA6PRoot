Privacy Policy

This policy describes how the personal NA60 MWPC Archive rclone configuration interacts with Google Drive. The static website itself does not provide a file upload, authentication or hosted storage service.

Effective date: 24 October 2026

1. What the application is

NA60 MWPC Archive is a personal workflow using the open-source command-line tool rclone to synchronize selected research files from a user's computer with the user's own Google Drive account. The tool is operated locally, and this website is informational only.

2. Google information accessed

When the user authorizes the Google Drive integration, rclone may access Drive file names, identifiers, paths, sizes, modification timestamps, checksums and file contents needed to perform the user's chosen commands. Depending on the command, it may also upload new files, replace existing files, create folders, or remove files. The Google Drive full-access OAuth scope, if selected, permits broader operations than a single upload.

No Gmail messages, Google Contacts or Google Calendar information are requested by this configuration. The data actually accessed depends on which commands and paths the user chooses.

3. How that information is used

Google Drive data is used only to perform the user's locally initiated file synchronization, backup, retrieval and integrity-verification operations. It is not used for advertising, profiling, sale, or training machine-learning models through this utility.

4. Storage and security

OAuth credentials and refresh tokens are managed by rclone in the user's local configuration, normally at ~/.config/rclone/rclone.conf, rather than by this public website. The user is responsible for restricting access to that configuration and local machine. The local files remain under the user's control; cloud copies are stored in the user's Google Drive account under Google's applicable terms and security practices.

This informational site contains no login form, OAuth callback, upload endpoint or analytics scripts. As a hosting provider, GitHub may process ordinary website access metadata under its own privacy policy.

5. Sharing and disclosure

The NA60 MWPC Archive workflow does not independently send Google Drive file contents to a separate application server, sell Google user data, or share it with advertisers. Data transfers are between the local rclone client and Google's Drive service, subject to the commands the user executes. The user may separately choose to share files from Google Drive or authorize other services; those actions are outside this rclone configuration.

6. Retention and deletion

Data remains on the local computer and/or in the user's Google Drive until the user modifies or deletes it. The user can revoke rclone's access in their Google Account's third-party access settings, remove the local rclone configuration, and delete archived Drive files using Google Drive. Revoking access does not automatically delete files previously uploaded to Drive.

7. Limited use

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements, insofar as they apply to this local personal workflow.

8. Changes and inquiries

This policy will be updated if the workflow's data practices change. For questions about this personal integration, the maintainer can be contacted through the repository issue tracker. Do not post personal research files, authorization codes or credentials in a public issue. The Google consent screen separately identifies the app's support email.
