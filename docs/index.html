A local-first archive for MWPC simulation results.

NA60 MWPC Archive is a personal command-line setup that uses rclone to transfer physics simulation results and analysis reports from a local computer to the owner's Google Drive. It is not a hosted file-management service.

Local processingUser-controlled transfersNo hosted app backend
01

What this utility does

Keep computation local

Geant4, Heed and Garfield-based MWPC simulations are executed on the researcher's own machine. This website does not execute or receive simulations.

Archive selected files

When the user runs an rclone command, rclone reads local files and communicates with the Google Drive API to list, upload, verify or retrieve selected research files.

Retain control

The user chooses which directories to copy and which Drive account and folder to use. Certain rclone commands can modify or delete Drive files, but only when the user explicitly executes them.

02

How access works

1

Authorize Google Drive

The user grants a locally installed rclone client access through Google's OAuth consent flow.

2

Store credentials locally

rclone stores the authorization token in the user's local rclone configuration. This public website does not receive OAuth codes, tokens or Drive files.

3

Transfer files on command

Data travels between the user's local environment and Google's infrastructure using the Google Drive API. No independent NA60 MWPC Archive server processes the files.

03

Permissions and privacy

The Google Drive OAuth permission may allow rclone to list, read, create, update and delete files in the user's Drive. The utility does not perform these operations merely because a user visits this site: actions are initiated by local rclone commands.

For a detailed description of the data accessed, stored and shared, please read the Privacy Policy.
