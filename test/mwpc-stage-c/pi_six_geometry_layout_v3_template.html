2. Время дрейфа — все камеры

Время от рождения электрона до сбора на аноде. Исходные бины 10 нс; можно объединить их в 20 или 50 нс без интерполяции.

Нормировка каждого варианта: все собранные первичные электроны с известным временем, включая хвост ≥300 нс. Отбор по углу входа мюона действует и для времени, и для карты камер.

3. Как электроны подходят к аноду?

Угол между последним микроскопическим шагом Garfield и внутренней нормалью к аноду. Не угол входа мюона.

Исходные угловые бины 10°; доступно суммирование до 20° или 30°. Выбранные камеры, анод, геометрия и угол входа мюона синхронизованы со временем. Для отдельного анода доступна только интеграция по всем углам мюона.

4. Шесть вариантов: сбор, Mean и centered RMS

Те же исходные Geant4/Heed-события и 6 разных Garfield LUT. Средние по собранным электронам — не весь исходный поток; эффективность может меняться. 5. Полярные распределения попадания электронов на анод (φ_hit)

Точка, где электрон достигает окружности анода: 0° = +u, 90° = +v, 180° = −u, 270° = −v. Это положение точки попадания, не направление скорости электрона. Шесть вариантов: шаг анода 3 / 3.5 / 4 мм, без и с field wire 75 мкм.

5a. Все углы входа мюона — по шесть круговых гистограмм

Каждый столбец — 10° по окружности. Радиальная высота — доля от электронов с известным φ_hit в данной конфигурации. Масштаб радиуса одинаков для всех шести графиков.

Численная интерпретация: Q₂ = ⟨cos(2φ_hit)⟩. Q₂ > 0 означает преимущественное попадание со сторон ±u; Q₂ < 0 — со сторон ±v. TV сравнивает форму нормированных распределений с field wire и без него; долю собранных электронов сравниваем отдельно.

5b. Зависимость от знакового угла входа мюона — по шесть круговых графиков

Каждая цветная линия — нормированное отдельно распределение P(φ_hit | θμ). Ось θu/θw берётся из верхнего выбора. По умолчанию показаны четыре наиболее заполненных угловых интервала для выбранных камер.

Полярные графики суммируют все аноды выбранных DET, даже если выше выбран отдельный анод: одинаковый номер проволоки при разном pitch не означает одинаковую физическую координату. Для нескольких камер берутся исходные histograms каждого DET и суммируются без пересчёта Garfield. Используются только исходные бины φ по 10° и сохранённые интервалы θμ; сглаживания и искусственных угловых данных нет.
