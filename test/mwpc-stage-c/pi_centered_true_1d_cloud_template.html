Как изменяются одномерные распределения электронного облака во времени?

Это \(P(u;t),P(v;t),P(w;t)\) для электронов, которые ещё дрейфуют в момент \(t\): реальные промежуточные точки Garfield, а не начальная координата против итогового времени прибытия.

← Время прибытия и кратность · ← Два анода, один мюон
Важно для PI. Каждая цветная кривая показывает координаты электронов в конкретный момент времени, а не их координаты рождения. Электроны, уже достигшие анода или потерянные, из распределения исчезают. Поэтому число оставшихся электронов убывает, и вероятность на каждой кривой нормирована на число ещё дрейфующих электронов в этот момент. Выборка ограничена мюонами из первых чанков, отобранными по углу; она не даёт детекторную эффективность.

Распределение координаты облака

Кривые по моментам \(t\) являются одномерными бинированными распределениями. Точки между реальными сохранёнными Garfield-микроступенями интерполированы; прямого соединения точки рождения с точкой сбора без траектории нет. Слабозаполненные моменты с менее чем 20 живыми электронами скрыты и помечены в легенде.

Сколько электронов ещё находится в дрейфе?

Здесь знаменатель постоянный: полное число запущенных микроскопических электронов данной угловой группы. Убывание обусловлено завершением их микроскопических треков (сбор или потеря). Это не число электронов в электрическом импульсе.

Метод: реальные местные Geant4 траектории мюонов; независимое Heed рождение электронов; отдельные новые Garfield AvalancheMicroscopic::DriftElectron траектории с EnableDriftLines() и сохранением промежуточных координат; срезы времени интерполированы только между соседними сохранёнными микроскопическими точками.
