4. Сколько разных анодов успевают собрать электроны?

Пример: если 40 электронов прибыли на проволоку №10, а один на №11 — кратность N=2, не N=41. Если на №11 электрон пришёл только после 100 нс, при T=100 нс было N=1.

P(N≥2) = доля реальных газовых хит-сегментов, для которых минимум две разные физические проволоки собрали первичные электроны внутри окна T. N=0 и газовые хиты без электронов входят в знаменатель.
