Настоящая траектория в газе; два физических анода, собравших первичные электроны; их распределения по времени прихода. Никаких условных напряжений, усиления или ASIC-порогов.

Выбор: нажми камеру на XY-карте, затем выбери мюон по углу \(\theta_u\). Гистограммы показывают количество собранных первичных электронов на каждом аноде за интервал времени. Сумма A+B — только сумма чисел электронов, не напряжение и не сложение реальных сигналов электроники. Два анода здесь определены по сбору хотя бы одного электрона без временного порога.

1. Станция: выбери камеру

Зелёные камеры содержат примеры двуханодных событий в пилоте; серые — нет. Номер DET подписан внутри каждой камеры. Оси глобальные, см.

2. Поперечное сечение камеры \(u\)-\(v\)

u — поперёк проволок; v — нормаль к камере. Катоды: \(v=\pm3\) мм, анодная плоскость: \(v=0\). Цветом выделены два анода, собравшие электроны. Белая стрелка — настоящий газовый сегмент мюона Geant4.

3. Сколько первичных электронов приходит на каждый анод?

Гистограммы накладываются полупрозрачно: бирюзовый — A, оранжевый — B. Тонкая пунктирная линия — число электронов A+B в том же временном бине. Временной нуль приближённо совпадает с рождением первичных электронов.
