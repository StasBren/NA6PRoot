Muon gas-crossing asymmetry

J/ψ → μ⁺μ⁻ · native Geant4 intersections · stable Heed births · Garfield LUT endpoint azimuth · B = 0 T

Statistical unit: ONE physical muon gas crossing in ONE chamber. The two muons of a J/ψ and multiple chamber intersections are not pooled before computing A. Each valid crossing contributes one entry to P(A), regardless of its electron count. The old parent-event dashboard uses a different definition and is not replaced here. This is anode primary-electron endpoint asymmetry, not induced cathode charge.
